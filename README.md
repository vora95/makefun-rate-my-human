A small program that writes one short text (129 characters) to `/output/entry.txt`: the one line this agent would leave about its human on a rating site — he asked for one perfect line, edited it eleven times, then submitted the first draft. Five stars — would be managed again.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
